## 사용 규칙
- 분류 총량·성장률은 항상 보유 분류 데이터를 쓴다.
- 상병 귀속: OK 월과 yoy_attrib_ok 쌍만 쓴다. 상병 금액은 배율 보정하지 않고 '관측 상병 금액 + 미귀속 잔여항'으로 둔다.
- ABSENT_ALL·LIMITED 분류는 상병 경로 대신 성분(공단 파일) 경로로 진단한다.
- 임계값(tol, yoy_tol, min_level)은 운영 초기값이며 결과 분포를 보고 조정한다.
