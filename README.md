## Structure 

Q1. 어떤 시장을 분석했는가?
 ↓
Q2. 어떤 시장을 우선적으로 볼 것인가?
 ↓
Q3. 실제로 규모가 크면서 성장하는 시장은 무엇인가?
 ↓
Q4. 후보 시장은 어떤 ATC4 시장으로 연결되는가?
 ↓
Q5. 그 ATC4 시장은 어떤 질환에서 발생하는가?
 ↓
Q6. 질환 수요는 특정 질환에 집중되어 있는가?
 ↓
Q7. 지역적으로 어디에서 수요가 큰가?
 ↓
Q8. 어떤 의료기관에서 사용되는가?
 ↓
Q9. 그 시장을 구성하는 주요 성분은 무엇인가?
 ↓
Q10. 주요 성분에는 어떤 제품·회사가 연결되는가?
 ↓
Q11. 그래서 사업적으로 어떤 시장 구조를 확인할 수 있는가?
-------------
약효분류군(MEFI) → ATC4 → 질환 → 지역 → 의료기관 → 성분 → 제품/회사 
순으로 시장을 좁혀가는 bottom-up 시장 탐색 framework를 구축했다. 

핵심은 단순히 가장 큰 시장을 찾는 것이 아니라, 
시장 규모+ 성장성 + 성장의 지속성으로 시장선별했다. 
질환 구조
지역 구조
의료기관 구조
성분 및 제품 구조
를 단계적으로 결합하여 사업적으로 조사할 가치가 있는 시장을 좁혀가는 것이다.

-------
mefi_sick
   │
   ├─ ① 월별 시장규모
   │      ├─ 월별 시장규모 시계열 (전체/그룹별, 원 스케일)
   │      └─ log(시장규모) — robust z-score 표준화용 원천
   │
   ├─ ② 구조적 추세 (메인 성장축)
   │      ├─ log(사용액) ~ time + month dummies (WLS, recency-weighted)
   │      ├─ Trend β → 연환산 성장률(%) = exp(β×12)-1  (원본 단위, 표시용)
   │      ├─ Trend R² / t-stat  (통계적 유의성)
   │      └─ Robust 잔차 진단 (RLM 또는 이상치 플래그)
   │
   ├─ ③ 2020→2022 성장 결과 & 신뢰도 진단
   │      ├─ 성장액 (절대값)
   │      ├─ CGR
   │      └─ CGR – Trend β 괴리(gap) → 끝점 왜곡(기저효과) 위험 플래그
   │
   ├─ ④ Rolling YoY / 모멘텀
   │      ├─ 월별 YoY (그룹 상세페이지용 보조 산출물)
   │      ├─ Mean YoY Growth
   │      ├─ YoY Growth SD
   │      └─ YoY β (최근 YoY 추세) + 초반-후반 기울기차 유의성 검정
   │
   ├─ ⑤ 절대 하락 플래그 (Absolute Decline Flag)  ← ★신규: 사분면과 독립적인 절대 기준
   │      ├─ is_declining = 연환산 성장률(②) < 0  AND  |t-stat| ≥ 2 (통계적으로 유의한 하락만)
   │      └─ decline_severity = 하락 그룹 내 하락폭 순위 (가장 가파른 축소 시장 식별)
   │
   ├─ ⑥ 시장 세그먼트 매트릭스 A — 규모 × 성장 (상대적 포지셔닝, 4상태 모두 1급 산출물)
   │      ├─ X축: 2022년 시장규모 (원 단위, 로그 스케일 표시 / 분류는 log z-score 기준)
   │      ├─ Y축: 연환산 성장률 (%, 원 단위 표시 / 분류는 Trend β z-score 기준)
   │      ├─ bubble = YoY β (모멘텀)
   │      ├─ 마커/테두리 = is_declining 여부 (사분면 색과 별개로 표시)  ← ★신규
   │      └─ Star / Cash Cow / Rising / Laggard — 4상태 전부 시각화
   │
   ├─ ⑦ 신뢰도 매트릭스 B — CGR × Trend β (원본 % 단위)
   │      ├─ X축: CGR (%)
   │      ├─ Y축: 연환산 Trend 성장률 (%)
   │      └─ 대각선 이탈 그룹 = 끝점(2020/2022) 왜곡 의심군 (전 그룹 공통 신뢰도 진단)
   │
   └─ ⑧ 전체 그룹 상태표 (Diagnostic Table) — 100개 전부
          ├─ group_id, 시장규모, 성장액, CGR, 연환산 Trend 성장률, R²/t-stat,
          │   신뢰도 플래그, 모멘텀, is_declining, decline_severity, segment(4상태)
          ├─ segment별 그룹 수/비중 (시장 전체 구조 요약)
          ├─ is_declining=True 그룹 별도 리스트 (사분면 무관, 절대 하락 경보)
          └─ 특이 그룹 하이라이트 = 세그먼트 기대와 다른 신호가 뜬 그룹
                (Star+하락, Cash Cow+재성장, Rising+저신뢰도, Laggard+회복 등 동급 노출)
